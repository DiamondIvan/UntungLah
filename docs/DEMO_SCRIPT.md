# Three-minute demo script

Open the app and confirm the coach source before judging. Use the fictional Warung Nasi Lemak sample throughout. If Qwen is unavailable, describe the labeled built-in explanation as the demo fallback.

| Time | What to show and say |
| --- | --- |
| 0:00–0:30 | Select **Start Guided Demo**. “This stall sold 40 packs at RM5. The records show RM200 coming in and RM140 going out. UntungLah uses those numbers to help the vendor learn what a pricing change might do.” |
| 0:30–1:05 | Open **Pricing Strategy**. Show RM5 minus RM3 gives RM2 per pack before other operating expenses. Complete the quiz with RM2, 40% and the answer about contribution under the stated assumption. |
| 1:05–1:55 | Open the pricing simulator and show the prefilled RM5.50 price, RM3 cost and 40 packs. Compare the RM80 baseline with RM100 adjusted gross contribution. “That is RM20 more if the stall still sells 40 packs. The vendor can also test a lower quantity here.” |
| 1:55–2:35 | Select **Explain This Decision** and show the source and assumptions. Read the practical next step aloud. |
| 2:35–3:00 | Save one of the suggested actions as a goal. The demo explanation suggests tracking unsold portions for five business days. Open **My Progress** and demonstrate completing the goal. |

## Judging evidence

- Capture the dashboard with its sample-data label and cash figures visible.
- Capture the quiz explanation and the pricing comparison at 40 packs.
- Capture the coach source badge and the saved goal. Use a live Qwen response only after verifying it in the app.
- Capture one narrow viewport with mobile navigation.
- If the team works in Qoder, capture a real discussion, code diff, test run or RepoWiki entry that demonstrates the work. Keep keys and personal data out of the frame.

## Team contribution notes

Record each verified activity with a teammate’s name, their contribution and an artifact such as a commit, working file, test output or Qoder discussion. Use the project areas below to organize the judging handoff.

| Area | Evidence to capture |
| --- | --- |

| Implementation | A calculation, record flow, lesson, quiz or simulation with a working diff |
| Debugging and tests | A reproduced issue, its fix and the test or manual check that confirms it |
